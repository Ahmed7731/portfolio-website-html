# 👤 Personal Profile Webpage

## 📌 Overview
This project is a simple **personal profile webpage** created as part of **Assignment 1** for the **Route Academy Full-Stack Diploma**.

It is built using **HTML** and **basic CSS styling only**, following the requirement that advanced CSS techniques are not used.

---

## 🛠️ Technologies Used
- HTML
- Basic CSS (inline / internal styling)

---

## 🎯 Features
- 👤 Personal profile layout
- 🧾 Simple and clean structure
- 🎨 Basic styling (no advanced CSS)
- 📱 Beginner-friendly design

---

## 📁 Project Rules
- ❌ No advanced CSS frameworks (like Bootstrap, Tailwind, etc.)
- ❌ No complex animations or styling
- ✅ Only basic HTML and simple CSS allowed

---

## 🚀 How to Run
1. Download or clone the repository
2. Open the folder
3. Run `index.html` in any browser
